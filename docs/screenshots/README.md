# README screenshots

These are browser captures of MK Redway Navigator **v0.14.17**, showing example journeys around public places in Milton Keynes. They contain no personal Home or Work addresses. Journey estimates and available routes can change with the map data and selected preferences.

| Image | What it shows | Source |
| --- | --- | --- |

| [Cultural Route](cultural-route.png) | A red joining journey and the Blue Cultural Route, with the original unverified-track notice. | Production release review, 28 October 2026. |

The production images come from the successful [v0.14.17 deployment review](https://github.com/tubbygregory/mk-redway-navigator/actions/runs/40607050882). The app source used for those captures matches the current application; the later README update changed documentation only. The images are copied without visual edits. Browser automation selected example journeys and controlled browser capabilities for the release checks; native sharing options depend on the user's browser. Mobile viewports are browser emulation, rather than physical iPhone testing.
